## Template for the final document

When a token is announced, this page should cover, in order:

1. **Purpose.** What the token does inside the protocol, and what it does not.
2. **Supply.** Total, circulating, and any issuance schedule.
3. **Distribution.** Every allocation with its recipient category, amount and unlock terms.
4. **Fees.** Whether protocol or relayer fees interact with the token.
5. **Governance.** Which decisions, if any, token holders influence.
6. **Verification.** The contract address, and where to cross-check it against official channels.

## Principles

- Publish allocations in full, including team and insider shares.
- Prefer on-chain verifiable schedules over promises.
- Never present an address as official before it is stated here and on the site.

This is not investment guidance.
